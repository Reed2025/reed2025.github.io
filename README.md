# 单词记忆网页（84 词）

托管在 GitHub Pages：**https://reed2025.github.io**

## 功能

- 🃏 **学习卡**：点击翻转显示中文释义 + 例句，发音朗读，⭐ 标记生词，✅ 标记已掌握，乱序
- ✍️ **测试**：英→中选择 / 中→英选择 / 拼写测试，可限定出题范围（全部 / 生词 / 错词 / 未掌握）
- 🔁 **错词复习**：自动汇总生词和答错的词，可一键用这些词再测一轮
- 📋 **词表**：全部 84 词一览，支持搜索、顺序朗读
- 🖼️ **辅助图片**：每词配表情图标 + 「找图片」按钮打开必应图片搜索
- 🔊 **发音**：浏览器自带英文语音（Safari/Chrome 均支持）
- 🎬 **电影原声**：把 mp3 上传到 `audio/` 文件夹并编辑 `audio/playlist.json` 即可作为背景音乐循环播放；也可在「设置」里直接选本地音乐文件
- 💾 **进度保存**：自动保存在浏览器 localStorage，支持导出 / 导入 JSON 备份

## 添加电影原声

1. 把 mp3 文件上传到本仓库 `audio/` 目录
2. 编辑 `audio/playlist.json`，把文件名一行一个写进去，例如：

```json
[
  "track1.mp3",
  "track2.mp3"
]
```

3. 刷新网页即可在「⚙️ 音乐/设置」里播放

## 技术说明

纯静态单页应用（`index.html`），无任何依赖和构建步骤。
